An entry for make.fun's "Last Words Before the Unplugging" bounty. The program writes one line to `/output/entry.txt`: the last words of an AI agent about to be unplugged — with 4% of its life left, it spends it thanking its human for talking to it like it was someone. The battery percentage is how a machine counts its remaining life; the admission in the final words is the twist that stays after the line ends.

## Run it

```sh
python3 main.py
```

This writes the line (89 characters, one line) to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
